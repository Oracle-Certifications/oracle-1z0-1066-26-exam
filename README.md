## 5. Scenario-Based Demo & Practice Questions

### Question 1
In Oracle Planning Central Cloud 2026, what action occurs when a planner marks a planned purchase order exception as approved in the plan output and clicks 'Release'?

A) The order is sent directly to the supplier's bank account
B) A purchase requisition or purchase order interface record is transmitted to Oracle Procurement Cloud for fulfillment
C) The item inventory is instantly deducted from the warehouse balance
D) The plan is permanently archived and cannot be re-run

- **Correct Answer**: `B) A purchase requisition or purchase order interface record is transmitted to Oracle Procurement Cloud for fulfillment`
- **Technical Explanation**: Releasing planned orders from Planning Central pushes actionable supply recommendations (Purchase Requisitions, Transfer Orders, or Work Orders) to execution systems like Oracle Procurement or Manufacturing.

### Question 2
Which capability enables planners in 2026 to test the impact of a sudden 30% surge in customer demand on factory line capacities without altering production planning data?

A) Direct database table editing
B) Creating a Plan Simulation (What-If Scenario)
C) Re-installing the planning instance
D) Running complete purge and reload

- **Correct Answer**: `B) Creating a Plan Simulation (What-If Scenario)`
- **Technical Explanation**: Simulations allow planners to duplicate an existing plan, adjust parameters (e.g. demand forecast, lead times, resource capacities), and compare outcomes side-by-side without affecting operational plans.
